## 本批目标和验收

用户明确授权以“在微信里搜索文件传输助手”为真实案例，继续完善按当前窗口执行口述步骤，更新本机并验证，不能写死单个软件或关键词。基线为干净 `codex/yuanshu` 的 `f7b89a30839eaad16cb102737b408eea8584e9dc`，前一候选的主动语音和应用打开必须保持。

本批实现通用搜索口述与可靠搜索控件的执行、回读和结果验证。具名软件仍按可信应用目录绑定目标；“当前窗口/在里面”仍绑定请求时的可信窗口。底层复用控件发现与写入能力，不增加另一份 Session 或授权状态。不同软件的兼容差异不得通过固定关键词或预造结果隐藏。

搜索词必须由用户原话解析。引用文字保持字面含义；未引用的追加发送、删除等操作不能被当成已授权步骤。写入前后持续核对窗口、进程与搜索控件身份；找不到唯一可靠搜索框时不向其它输入框尝试。实时筛选与 Enter 提交须区分，不能用 Enter 意外打开会话后仍声称只搜索。结果只根据本次输入关联的可验证界面记录，输入成功不能冒充结果验证成功。停止、替换和重复确认维持原取消及单次执行边界。

实施顺序：本机控件诊断；语言回归与通用执行适配；受影响测试及独立审查；干净源码完整构建；安装包隔离验证；备份并更新本机；真实产品文字与真人口述验收。至少增加其它搜索词或软件场景，证明查询没有写死。测试夹具使用虚构软件、控件和关键词；私人窗口、日志和数据只留仓库外。

本批不自动扩大到任意点击、聊天正文输入、消息发送或全软件兼容。若实际软件未暴露可访问控件，应如实记录并评估所需兼容路线，不伪造通过。捕获画面仍须本次运行内的单窗口可见同意。
