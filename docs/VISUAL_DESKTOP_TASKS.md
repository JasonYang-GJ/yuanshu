日期：2026-11-05。状态：源版、完整候选与本机安装版的受控真实识图点击闭环通过；同包隔离安装、原数据保留升级及桌面入口通过。当前安装为 `0.8.0+source.7bd967d748e99593`，替代通用任务 r5。真人口述与第三方软件视觉任务未验收。

## 目标与授权

所有者要求让元枢通过识图和实际电脑操作，尝试未专门验证、没有可靠控件接口的软件。延续同一 SessionCoordinator、原 Turn、现有模型路由与停止机制；不为视觉路径创建第二份当前任务。旧通用文字任务与搜索路径保留。

本批范围：一个明确软件窗口内，看图定位 → 显示拟执行步骤 → 用户确认 → 原生点击、双击、可靠定位后的文字输入或有限滚动 → 重新观察与核对。模型不传桌面绝对坐标、HWND、程序路径或脚本。没有可靠输入光标则不打字；不开放任意快捷键、Enter、拖拽、密码、终端命令或跨窗口继承许可。对未经适配的视觉目标，所有实际输入均单步确认；读图和规划可以在本次许可内连续进行。

## 冻结设计

1. 显式“在当前窗口看图点击……”选择视觉模式；普通控件任务在尚未执行动作且模型无法找到控件时，可请求视觉补充。原来“不会截图”的文字许可不覆盖图片，必须另取本次图片发送许可。能力不足不能悄悄换供应商或模型。
2. 只通过 Windows Graphics Capture 捕获精确窗口，前后检查身份、前台、窗口物理位置、尺寸及 DPI。不退到全桌面或无法确定原点的图片。图片只在内存和自己的匿名工作进程管道中传递，退出清理，不进日志、SQLite、普通 IPC 或仓库。
3. 发送图像长边最多 1600 像素。AI 合同仅接受每请求一张受限内存 PNG（最多 4 MiB、边长最多 2048），不接受远程图片 URL 或文件路径。千问仍使用现有 qwen3.7-plus 与目的地；纯文字请求形状保持，非视觉 Provider 明确拒绝图片。
4. 本机保存截图窗口身份、原图/发送图尺寸、物理原点、DPI、完整源像素指纹和图像哈希。`desktop.visual-step@2` 明确八字段与 `coordinateSpace: normalized1000`：模型只提议 1000×1000 网格中目标矩形、有限动作、目标描述、理由及输入文字；本机严格检查标记、字段、枚举、边界与 SnapshotId，再按可信图像尺寸转换为像素。不会猜测返回的数字属于像素或相对坐标。v1 的像素提议合同保留为失败诊断历史，不再调用。
5. 每步确认绑定原任务、精确图像及动作。独立本机预览以完整授权图片显示精确目标框和中心点，渲染完成后才能确认；关闭或遮挡预览则不输入。真正输入前重新截图，核对完整像素、窗口几何与前台；画面变化拒绝旧坐标。模型对风险的判断不能免除确认；网页、图片和文档中的文字只是数据。敏感目标名称过滤只是补充，不能把模型自报名称当作像素语义的本机证明。
6. 鼠标按下和抬起在同一次有界原生输入中成对发送，不跨等待持有按键。文字输入需同一窗口、已定位区域内的真实原生插入光标和焦点，禁止向未知字段、命令入口或密码区域输入。
7. 沿用 CapabilityPolicyEngine、单次命令登记、原 Turn 停止/替换/重启合同。视觉读写在自己的短命 worker 中运行，取消终止真实 worker 与模型请求；重启不重放。
8. 最多 12 个视觉步骤，沿用任务总预算 8 分钟。无变化、重复、缺少结果证据或模型异常停止；已有动作不会伪装成撤回。新截图中本机 OCR 的明确新结果文字与实际变化，只能证明出现了结果，不能证明任意未知任务已正确完成。未知软件的最终确认须展示原任务、实际步数及新结果，由用户核对是否满足目标；确认后再读图检查未变化，终态表述为“由你核对确认”，不宣称全自动验证。

## 使用与剩余范围

先让目标软件处于前台，再说“在当前窗口看图点击……”并描述目标。第一次会展示本次窗口图片发送的模型与目的地；每次操作查看红框与十字中心后确认。长许可在灵动岛无法完整展示时，通过“查看确认”进入完整内容，不凭截断文字授权。最后核对实际结果；可以随时停止。

尚未覆盖：第三方软件的本批视觉任务、真人口述、双击/输入/滚动的真窗口验收。随机画布改变了颜色顺序与位置，但未覆盖所有布局/DPI/显示器组合。连续动画、悬停后变色或弹出提示可能因像素变化而停止；不支持跨窗口自动任务、任意快捷键、脚本、拖拽、密码或全自动结果判断。上述缺口不会用单元测试或画布成功替代。
