# 通用桌面任务：实现与验收

日期：2026-11-04 至 2026-11-05。状态：通用任务框架已随 r5 本机交付，版本 `0.8.0+source.96df0ba66592f5d8`。r5 安装版 Excel 两格原生写入与计算器多步运算通过；r3 安装版 Word 正文与浏览器表单通过。长许可保留任务并转手动全文确认，短步骤确认完整可见；实际麦克风开启与停止已验证。真人口述通用任务仍待用户验收，不宣称任意软件、跨窗口复杂流程或识别稳定性均已实现。

## 用户目标与本批范围

用户明确要求根据语音指令操作各种软件、自动完成任务，不再停留于打开 Steam。此次授权覆盖一个可复用的多步执行框架及安装验收，不延续早期只准打开/搜索的功能上限。

通用任务在同一个 Session/Turn 中运行：绑定用户指定的软件或当前窗口 → 可见确认本次窗口文字发送至当前模型的用途/目的地 → 有界读取真实控件 → 模型提议一步 → 本机验证和执行 → 重新读取并检查 → 继续或报告。动作包括控件调用、明确文本框填写、选择、展开/收起、滚动和等待。不得从模型或窗口文字扩大软件目标或用户任务。

本批优先 Windows UI Automation（软件提供的结构化按钮、文本框与菜单接口），不把文字模型伪装成视觉模型。未提供可靠控件的软件会说明缺口，不按猜测坐标点击。支持不同软件的相同控件接口，不为每个任务写固定脚本。真实验收使用独立测试内容的浏览器及常用桌面程序；不得以合成夹具通过替代真实程序。

实际软件检查触发两项补齐：通用网格层按 GridItem、网格、行列、跨度与完整快照绑定普通文字/数字；Excel 的 ValuePattern 写入回执与实际单元格不符，因此可信 Office16 Excel 改走绑定窗口的原生单元格对象，读写均以 Range.Value2 为准，禁止公式与命令表达式。Word 正文仅提供只读文字接口，因此接入绑定 HWND/进程的原生文档对象，限短篇纯正文，不使用全局 ActiveDocument、不执行宏、不自动保存。Word 只读、保护、修订、表格、嵌入对象等内容不开放全文写入；非空正文保留覆盖确认。Word 已通过安装版任务与独立原生文档对象全文回读；Excel 的早期 UIA 成功记录已撤回，原生修正的正常产品验收单独记录。

Windows 商店版计算器绑定 CoreWindow 内容窗及可信系统 ApplicationFrameHost；仅元数据解析唯一直属内容窗，不读取宿主兄弟窗口。新启动内容窗先等待系统宿主稳定，再展示许可。已实测的中文系统计算器数字/基本运算键在任务许可后连续执行；仅对精确系统包路径、窗口身份、按钮类型、编号和名称匹配生效，清除、历史/内存与其它按钮继续单步确认。

任务内普通步骤自动执行；发送、发布、支付、删除、保存/覆盖、账户与安全变更、无法判断实际后果的控件调用必须显示目标和本步内容并单独确认。密码及凭据字段、系统命令入口、提权和任意脚本不开放。屏幕/网页/文档文字始终是数据，不能授予权限。不同窗口不能继承许可。

## 架构合同

- 唯一 SessionCoordinator 协调原 Turn、停止、替换、确认和结果。新增 DesktopTask 意图及执行服务，不建立另一份当前任务。
- 保留每 Turn 冻结 Provider/Model；复用 IChatModelProvider 与 ModelRouter 串行调用，严格解析有限 JSON 动作，模型只选当前快照中的局部控件编号。运行 Prompt 注册版本/hash并记录每次 AI 调用；不持久化完整控件树、凭据或截图。
- 模型控件编号优先采用快照内唯一的 AutomationId 可读别名，重复或无效标识使用局部序号；严格验证后精确映回原生控件，不接受模糊匹配。步骤历史明确记录已执行，不能把缺少直接结果回读误当作未调用而重复累加操作。
- `desktop.task-step@2` 明确完成证据直接摘取单个控件的原始 name/value；禁止给实际文字自行加 `value=` 或拼接多个字段。实测千问在 Excel 两格已写对后输出 `value=林舟`，因不在真实字段中被严格解析拒绝；修正提示示例，不放宽解析器，旧 @1 保留。后续规划失败时说明此前实际执行步数，不把先前操作假装撤回。
- 普通聊天升级到 `chat.general@4`：明确区别本轮尚未执行与产品已有本机任务能力，给出具体可用表达，不再把未匹配的指令笼统解释成整个产品只能聊天。聊天本身仍无执行权，旧提示词版本原样保留。失败界面优先显示具体失败原因，不沿用最后一条“正在执行”进度。
- 每个快照/动作绑定精确 HWND、PID、创建时间、程序路径和窗口类；控件绑定 RuntimeId、所属根、类型、名称及支持的 Pattern。任务内窗口标题可变化；不全局改变旧 WindowIdentityContract。动作前重新验证，不沿用变化或消失的控件。
- 滚动使用声明的 ScrollPattern；观察保留 ScrollBar 自身，不遍历其会自动显示/隐藏的辅助按钮。业务按钮、文字、选择和完整快照比较不变，避免滚动条辅助节点改变有界遍历列表而误停。
- UWP 另绑定承载窗口身份；Word 文档及网格行列身份只以本机哈希进入动作指纹，不发送模型。完整许可详情只在活动 Turn 内存存在，数据库保存固定等待摘要和动作哈希。
- Excel 另核对 EXCEL7 子窗口、原生 Window.Hwnd、工作簿名称/完整名/创建时间、工作表及单格地址，并在写前重验真实旧值、保护状态与对象身份。一次观察只建立一份有界可见单元格索引，退出即清；动作与最后写入边界不使用该索引，重新检查唯一性。重复 RuntimeId、重复地址及行列不符均停止；不采用全局活动工作簿。
- 每个原生 UIA 读取/动作运行在短命、受父进程管理的本机子进程中。匿名 stdin/stdout 传递有界 JSON；取消或超时终止该任务自己的工作进程，避免阻塞 UIA 调用在停止后继续执行下一步。已经发生的系统动作不会虚构为可撤回。
- 绑定/观察单次预算为 15 秒；执行包含重新定位、完整上下文校验和结果回读，预算为 45 秒。真实 Word 完整执行约 17 秒，原 15 秒执行预算不足；加长预算不改变停止时立即终止工作进程的边界。
- CapabilityPolicyEngine 新增明确任务步骤能力，使用确定性作用域和一次性授权；持久化每步命令摘要/状态，不存窗口全文。未知效果停在可见确认，确认绑定本次控件/动作/版本且只消费一次。
- 重启中断任务，不自动重放。执行有步骤/时间/内容预算；重复无进展停止。完成需要新的真实控件结果支持，不能只相信模型一句“完成”。

## 使用方式与已知边界

使用现有语音入口或会话输入，明确说明软件和任务，例如“使用计算器，计算23加19”，或先切到目标窗口再说“在当前窗口把A1填成合成验收，再把A2填成林舟”。解析也接受“用Word写入……”“用Excel在A1输入……”等明确操作表达；普通提问、引述、否定和已有简单打开/搜索路径保持分开。

本次窗口任务提示显示后可说“允许这次任务”或“拒绝这次任务”；具体步骤提示显示后可说“确认这一步”或“拒绝这一步”。许可绑定当前可见任务和步骤，“好”等普通回答不会扩大授权。原有“停止”会取消当前真实执行。

当前仍是一个明确软件窗口内的有界流程。跨窗口跳转不继承许可；没有可靠控件的软件、任意坐标/键盘脚本、密码输入、复杂Word结构与Excel公式不在已实现范围。最多24步、8分钟，单次文字最多1500字符。真实通过几个软件不代表任意软件或所有任务均可用；真人语音与文字入口、模型规划与原生执行、开发侧与安装版验证必须分别记录。

Excel 当前限可见且唯一识别的普通单格，格式为 General、G/通用格式或文本；不改格式、不保存。只读、VBA、保护、合并格、公式/数组与表格对象不开放写入；日期式内容、前导零数字及不能无歧义精确表示的数字拒绝输入。布尔值或错误值等非普通标量目前会停止该窗口的观察，不能据此声称复杂工作簿可用。
